# FuncUI

Reactive interfaces. Just JavaScript.

Библиотека на ES Modules без runtime-зависимостей. Теги создают настоящие
DOM-элементы; `$()` делает обычные объекты и массивы реактивными.

```js
import { $, mount, div, h1, p, button } from 'funcui';

const state = $({ count: 0 });
const app = mount('#app', () => {
  div(() => {
    h1('Counter');
    p(() => state.count);
    button({ onClick: () => state.count++ }, 'Increment');
  });
});

// app.unmount();
```

Публичный API: `$`, идентичный алиас `reactive`, `mount`, `For`, `insertHTML`
и функции HTML-тегов.
Теги принимают необязательные атрибуты и содержимое: строку, число, элемент или
синхронный callback. Callback также может вернуть `null`, `undefined` или массив
элементов/текста, например результат `.map()`.

Для вставки готовой HTML-строки внутри render callback используйте `insertHTML()`:

```js
import { div, insertHTML, p } from 'funcui';

div(() => {
  p('Before');

  insertHTML(`
    <p>HTML with <strong>emphasis</strong>.</p>
    <p>Another paragraph.</p>
  `);

  p('After');
});
```

Функция вставляет узлы на месте вызова без обёртки, сохраняет соседей и возвращает
`undefined`. Принимается только строка; пустая строка ничего не добавляет.
**HTML не очищается: за доверие к источнику и санитизацию отвечает разработчик.**
Содержимое разбирается через `<template>`; скрипты не активируются вручную.
Выражения FuncUI внутри строки не обрабатываются. Обычные строки в `p()` и других
HTML-функциях по-прежнему выводятся как текст.

`div(() => insertHTML(state.markup))` обновляется через окружающий структурный
callback: изменение строки пересоздаёт содержимое `div`, сохраняя сам `div`.
Отдельный callback-аргумент у `insertHTML()` отсутствует. При обновлении или
размонтировании вставленные узлы удаляются вместе с окружающей разметкой.

`p(state.count)` подписывает окружающий RenderScope и при изменении состояния
пересоздаёт его содержимое. `p(() => state.count)` сохраняет элемент и текстовый
узел, меняя только текст. Вложенные callbacks и вычисляемые атрибуты изолированы.

```js
button({ disabled: () => state.count >= 10, onClick: () => state.count++ }, 'Add');
div({ style: 'color: red;' }, 'CSS string');
div({ style: { opacity: () => state.count > 0 ? 1 : 0.5 } }, 'CSS object');
```

События — обычные listeners. Данные меняются синхронно, обновления DOM глобально
группируются через `queueMicrotask()` без дополнительного синтаксиса. Один effect
выполняется не более одного раза за flush; повторная инвалидизация уже выполненного
effect переносится в следующую microtask. Ошибки не останавливают остальные jobs.
Компоненты — обычные JavaScript-функции. Условия и циклы пишутся внутри callbacks.
Внутри `mount()` или callback HTML-функции компоненту не нужен `return`:
элементы автоматически добавляются текущему родителю. `return div(...)` тоже
поддерживается, если нужен созданный элемент. Один компонент можно собрать
из нескольких локальных функций, экспортируя только основную.
Для вычисляемого текста остаются обычные правила JavaScript: `() => state.count`
возвращает значение автоматически, а в блочном callback нужен явный `return`.
`mount()` принимает селектор или элемент, очищает контейнер и возвращает
`{ unmount() }`; размонтирование удаляет подписки и обработчики.

Для динамических коллекций используйте `For()` внутри render callback:

```js
import { For, ul, li } from 'funcui';

ul(() => For(
  () => state.users,
  user => li(() => user.name),
  user => user.id
));
```

Коллекция — массив обычных объектов с уникальными строковыми или числовыми ключами.
Существующие ключи сохраняют DOM при перестановке и замене объектов. `user` —
стабильный Proxy-ссылка на актуальный объект с этим ключом, его идентичность
отличается от элемента исходного массива. Удаление строки освобождает её зависимости
и обработчики. Дубликаты ключей вызывают ошибку, сохраняя последний рабочий список.
Обычные циклы и `.map()` также поддерживаются.

Реактивны обычные объекты и массивы, включая вложенность и циклические ссылки.
Специальные объекты вроде Map/Set/Date внутри состояния сохраняются без Proxy.
Асинхронный рендер, Virtual DOM, JSX, SSR и SVG не входят в Stage 1.
Структурный callback пересоздаёт своих детей; их фокус может сброситься.
Для точечного обновления строк используйте callbacks текста и атрибутов внутри `For()`.

В монорепозитории выполните `npm install`, `npm test` и `npm run dev` из корня.
Разработка идёт непосредственно из `src/index.js`, без сборки библиотеки.
Подробная архитектура, правила API и ограничения описаны в корневом `README.md`.
